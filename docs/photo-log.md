## Convenciones para futuras subidas

Cuando el usuario suba fotos por chat, mejor referirlas por:
- ID de archivo: `species-B-XX-Y_YYYYMMDD-HHMMSS.jpg` o equivalente.
- Lote/contexto: "Lote A del vivero", "Vista panorámica del fondo", etc.
- Fecha y hora del overlay (si tiene).

Cuando subo fotos al repo, las commiteo a `docs/images/uploads/<plant_id>/` con la convención de filename + entry en `docs/uploads.json` con `note` descriptivo. Y agrego acá una entrada en photo-log.

Si el usuario menciona "fotos de X" y no encuentro, primero buscar en este log antes de revisar todos los uploads.
